# Paper Notebook Light - Landing Page

Landing page for the [Paper Notebook Light VS Code Theme](https://github.com/kpab/vscode-paper-like-theme).

## Features

- **Bilingual Support**: Switch between English and Japanese
- **Responsive Design**: Works on all devices
- **Paper-like Aesthetics**: Mimics the warm feel of writing on paper
- **SEO Optimized**: Meta tags and structured data
- **Smooth Animations**: Engaging scroll effects and transitions
- **PWA Ready**: Includes manifest.json for progressive web app support

## Tech Stack

- Pure HTML5, CSS3, and JavaScript (no frameworks)
- Google Fonts (Inter, JetBrains Mono)
- CSS Grid and Flexbox for layout
- Intersection Observer API for scroll animations
- LocalStorage for language preferences

## Development

1. Clone the repository:
   ```bash
   git clone https://github.com/kpab/vscode-paper-like-theme-page.git
   cd vscode-paper-like-theme-page
   ```

2. Open `index.html` in your browser or use a local server:
   ```bash
   # Python 3
   python -m http.server 8000

   # Node.js
   npx serve
   ```

3. Visit `http://localhost:8000`

## Color Palette

The landing page uses the same color palette as the theme:

- Background: `#F5F0E6` (Warm paper color)
- Primary: `#854D2C` (Deep brown)
- Text: `#3A2E23` (Ink-style dark brown)
- Accent: `#A86434` (Orange-brown)
- Secondary: `#9E9386` (Pencil-gray)
